Halcora

A desktop that stays out of your way.

This page is the browser version of the sizing rule in Halcora.exe. A browser cannot start a virtual machine, cannot boot Halcora, and cannot read how much memory you are using, so you type that in. Halcora.exe does the real work on Windows. The checks at the bottom run the same rule against known cases.

This PC

Browsers report memory only roughly, capped at 8 GB, and cannot see memory in use.

Not much memory is free, so Halcora will run slowly. Close some apps for a better result.

Which image this PC would get

Two images are built from the same profile and differ only in what is installed. Halcora.exe picks one from your memory and cores; you can disagree with it.

    Disk

    There is no size to choose. The disk file starts near empty, grows only as Halcora writes to it, and shrinks again when files are deleted inside it. The 64 GB figure is a ceiling, not space that is reserved.
